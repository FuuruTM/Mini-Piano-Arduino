# Mini Piano using Arduino

A simple mini piano project using Arduino with 8 buttons and 8 LEDs. Each button represents a different musical note, from low Do to high Do.

## How It Works

* Each of the 8 buttons represents one musical note.
* Pressing a button plays its corresponding note.
* Each button is paired with an LED that lights up when the note is played.
* The notes range from low Do to high Do.

## Components

* Arduino Uno
* 8 Push Buttons
* 8 LEDs
* Buzzer
* Resistors
* Jumper Wires
